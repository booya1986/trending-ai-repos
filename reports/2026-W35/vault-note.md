## [tt-a1i/archify](https://github.com/tt-a1i/archify) — `JavaScript`
`agent-skills` `architecture-as-code` `architecture-diagram` `claude-skill`

**Stats:** ⭐ 26,258 · created 2026-04-15

**What it does / מה זה עושה:** Archify הוא agent skill ל-Cursor, Claude Code, Codex CLI ו-OpenCode שהופך קודבייס או תיאור מערכת למפת מערכת אינטראקטיבית ומלוטשת, ישירות בתוך הצ'אט. הסוכן מייצר JSON IR מוקלד ו-Archify מקמפל אותו באופן דטרמיניסטי ל-HTML/SVG עם חמישה סוגי דיאגרמות, ארבע פריסטים ותמות כהות/בהירות.

_Archify is an agent skill for Cursor, Claude Code, Codex CLI, and OpenCode that turns a codebase or system description into a polished, interactive system map directly in chat. The agent produces typed JSON IR and Archify deterministically compiles it into HTML/SVG with five diagram types, four presets, and dark/light themes._

**Why it's trending / למה זה בטרנד:** הכלי פונה לבעיה אמיתית של תיעוד ארכיטקטורה שנשבר: הוא מאפשר להשוות שני סנאפשוטים מאומתים כ-Before/Delta/After לפני מיזוג קוד, כולל עובדות מדויקות על מה נוסף, הוסר, שונה או הוזז. הוא גם תומך בזרימות עבודה גרסתיות מאומתות (revision-verified source) ומייצא קבצים משותפים כמו PNG, SVG, WebM וכרטיסי שיתוף.

_The tool addresses a real pain point in architecture documentation by letting teams compare two validated snapshots as Before/Delta/After before merging code, with exact facts on what was added, removed, changed, or moved. It also supports revision-verified sourcing and exports self-contained shareable files like PNG, SVG, WebM, and share cards._

**Example use case / דוגמת שימוש:** מפתח יכול לבקש מהסוכן: 'Use archify to map this repository's runtime architecture' ולקבל מפה חזותית מלאה של המערכת ישירות בצ'אט, כולל אפשרות לחקור צמתים, לעקוב אחרי מסלולי upstream/downstream ולהשוות תפקידים בין רכיבים.

_A developer can simply ask the agent 'Use archify to map this repository's runtime architecture' and receive a full visual system map directly in chat, with the ability to search nodes, trace upstream/downstream routes, and compare roles between components._

**Why it matters for you / למה זה רלוונטי לך:** לאבי זה רלוונטי כי זהו agent skill אמיתי שמתחבר ישירות ל-Claude Code ולכלים אחרים ומבצע עבודה ממשית: הבנת ארכיטקטורה וויזואליזציה שלה, בלי להמציא מבנה טופולוגי. זו דוגמה טובה לאיך agent skills הופכים כלי פרודוקטיביות למוצר שלם עם פלט ניתן לשיתוף.
