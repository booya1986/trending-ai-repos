## [morluto/rea](https://github.com/morluto/rea) — `TypeScript`
`agent-skills` `ai-agents` `binary-analysis` `claude-code`

**Stats:** ⭐ 279,751 · created 2026-04-14

**What it does / מה זה עושה:** REA הוא כלי MCP אחד להנדסה לאחור שמאפשר לסוכני AI (כמו Claude Code) לנתח התנהגות אפליקציות ובינארים, מרמת הפיצ'ר ועד רמת הקוד הבינארי. מותקן בפקודה אחת (npx rea-agents setup) ומשלב סוכנים, כלי ניתוח ו-decompiler תחת ממשק אחיד.

_REA is a single MCP for reverse engineering that lets AI agents (like Claude Code) analyze app behavior and native binaries, from a feature down to the binary level. It installs with one command (npx rea-agents setup) and bundles agents, analysis tools and decompiler integration under one interface._

**Why it's trending / למה זה בטרנד:** הריפו צבר כמות עצומה של כוכבים ותורגם לעשרות שפות, סימן לאימוץ רחב מאוד ולביקוש לכלים שמחברים סוכני AI לעבודת הנדסה לאחור מורכבת. השילוב עם Claude Code, agent-skills ו-MCP ממקם אותו בדיוק במגמה של סוכנים שמבצעים עבודה טכנית אמיתית.

_The repo has amassed an enormous number of stars and been translated into dozens of languages, signaling very broad adoption and demand for tools that connect AI agents to serious reverse-engineering work. Its integration with Claude Code, agent-skills and MCP places it squarely in the trend of agents doing real technical work._

**Example use case / דוגמת שימוש:** מפתח רואה פיצ'ר מעניין באפליקציה ורוצה להבין איך הוא בנוי: הוא מריץ את REA והסוכן חוקר את ההתנהגות בזמן ריצה ויורד עד לניתוח הבינארי עצמו, כולל חיבור לכלים כמו Hopper. כל זה מתבצע דרך ממשק MCP אחיד בלי להחליף כלים ידנית.

_A developer sees an interesting feature in an app and wants to understand how it works: they run REA and the agent investigates runtime behavior down to analyzing the native binary itself, including bridging into tools like Hopper. All of this happens through one unified MCP interface without manually switching tools._

**Why it matters for you / למה זה רלוונטי לך:** עבור אבי זה דוגמה מובהקת למגמה של סוכנים וכלי MCP שהופכים משימות טכניות מורכבות (הנדסה לאחור) לזרימת עבודה שסוכן AI יכול לבצע בעצמו. זה רלוונטי לנושא הליבה שלו: agents, MCP וכלי Claude שמבצעים עבודה אמיתית.

_For Avi this is a clear example of the trend of agents and MCP tooling turning complex technical tasks (reverse engineering) into a workflow an AI agent can execute itself. It is directly relevant to his core focus on agents, MCP and Claude tooling doing real work._

## [heygen-com/hyperframes](https://github.com/heygen-com/hyperframes) — `TypeScript`
`ai` `animation` `ffmpeg` `framework`

**Stats:** ⭐ 64,850 · created 2026-03-10

**What it does / מה זה עושה:** HyperFrames היא ספריית קוד פתוח שהופכת HTML, CSS, מדיה ואנימציות ל-MP4 דטרמיניסטי. אפשר להשתמש בה דרך CLI מקומי, מתוך סוכני קידוד AI באמצעות skills, או כמנוע רינדור מאחורי כלי יצירה מתארחים.

_HyperFrames is an open-source framework that turns HTML, CSS, media, and seekable animations into deterministic MP4 videos. It can be used locally via CLI, from AI coding agents using skills, or as the rendering core behind hosted authoring workflows._

**Why it's trending / למה זה בטרנד:** הפרויקט מתאים ישירות לגל הסוכנים: יש תמיכה רשמית ב-Claude Code plugin, סקילים ל-Copilot, Cursor, Gemini CLI ו-OpenCode, עם 21 skills מפורסמים וראוטר שמתקין workflows לפי דרישה. הכותרת 'Built for agents' והאינטגרציה העמוקה עם MCP/Claude tooling הופכות אותו לדוגמה בולטת לכלי יצירה שנבנה מהיסוד עבור סוכני AI.

_The repo is built squarely for the agent wave: it offers a versioned Claude Code plugin, standalone skills for Copilot, Cursor, Gemini CLI, and OpenCode, with 21 published skills and a router that installs creation workflows on demand. The tagline 'Built for agents' plus deep Claude/MCP tooling integration make it a standout example of a creative tool designed from the ground up for AI agents._

**Example use case / דוגמת שימוש:** דוגמה: מתקינים את ה-plugin עם `claude plugin install hyperframes@hyperframes`, מפעילים את `/hyperframes:hyperframes` ב-Claude Code, והסוכן יכול לכתוב HTML ולרנדר אותו ישירות לווידאו MP4 באמצעות ה-core skills.

_Example: install the plugin with `claude plugin install hyperframes@hyperframes`, run `/hyperframes:hyperframes` inside Claude Code, and the agent can write HTML that renders directly into an MP4 video using the core skills set._

**Why it matters for you / למה זה רלוונטי לך:** עבור אבי זה כלי שממחיש בדיוק את המעבר מיצירת תוכן ידנית לייצור וידאו אוטומטי על ידי סוכנים, רלוונטי גם ליצירה קריאטיבית וגם לעבודה עם MCP וכלי Claude. שווה לעקוב כדוגמה לאיך 'agentic creative production' נראה בפועל.

_For Avi this is a clear example of the shift from manual content creation to agent-driven video production, relevant both to creative production and to the MCP/Claude tooling ecosystem he tracks. It's worth watching as a concrete instance of what 'agentic creative production' looks like in practice._
