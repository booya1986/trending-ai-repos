## [vectorize-io/hindsight](https://github.com/vectorize-io/hindsight) — `Python`
`agentic-ai` `agents` `ai-memory` `memory`

**Stats:** ⭐ 44,496 · created 2025-10-30

**What it does / מה זה עושה:** Hindsight היא מערכת זיכרון לסוכני AI שמטרתה לגרום לסוכנים ללמוד עם הזמן, לא רק לזכור היסטוריית שיחה. היא כוללת שרת, קליינטים, MCP server ו-LLM wrapper בשתי שורות קוד, עם מושגי ליבה כמו retain, recall, reflect, observations ו-mental models.

_Hindsight is an agent memory system built to make agents learn over time, not just recall conversation history. It ships a server, clients, MCP server, and a 2-line LLM wrapper, built around core concepts like retain, recall, reflect, observations and mental models._

**Why it's trending / למה זה בטרנד:** הפרויקט טוען לביצועים state-of-the-art במשימות זיכרון ארוך טווח, ומציג את עצמו כפתרון שמתגבר על חולשות של RAG וגרפי ידע. יש לו נייר מחקר נלווה, בנצ'מארקים פומביים ותמיכה נרחבת בפלטפורמות וסוכני קוד.

_The project claims state-of-the-art performance on long-term memory tasks and positions itself as solving shortcomings of RAG and knowledge graphs. It backs this with a published paper, public benchmarks, and broad support across platforms and coding agents._

**Example use case / דוגמת שימוש:** מפתח סוכן קידוד יכול לחבר את Hindsight דרך MCP server כך שהסוכן יזכור העדפות קוד והקשר פרויקט לאורך זמן, במקום לאבד הקשר בכל שיחה חדשה.

_A developer building a coding agent can connect Hindsight via its MCP server so the agent retains coding preferences and project context over time, instead of losing context in every new session._

**Why it matters for you / למה זה רלוונטי לך:** עבור אבי, זה בדיוק סוג התשתית שהופכת סוכנים משיחה חד-פעמית לכלי עבודה אמיתי שמשתפר עם שימוש, רלוונטי ישירות ל-agents, MCP וטכניקות שמוציאות יותר ממודל.

_For Avi, this is exactly the kind of infrastructure that turns agents from one-off conversations into real working tools that improve with use, directly relevant to agents, MCP, and techniques for getting more out of a model._

## [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail) — `JavaScript`
`agent-skills` `ai-agents` `claude` `claude-code`

**Stats:** ⭐ 151,054 · created 2026-06-12

**What it does / מה זה עושה:** Ponytail הוא סקיל לסוכני AI (Claude Code, Cursor ועוד) שגורם להם לכתוב כמה שפחות קוד, בסגנון של מפתח סניורי עצלן שכותב שורה אחת שעובדת. הוא עובד עם 20 סוכנים שונים ונשמר כ-agent skill או cursor rule.

_Ponytail is a skill for AI coding agents (Claude Code, Cursor, and others) that pushes them to write as little code as possible, like a lazy senior dev who writes one line that just works. It works across 20 different agents and ships as an agent skill or cursor rule._

**Why it's trending / למה זה בטרנד:** המדדים שפורסמו מרשימים: כ-54% פחות קוד בממוצע (עד 94% במקרים מסוימים), כ-20% זול יותר וכ-27% מהיר יותר, תוך שמירה על כל אמצעי הבטיחות. הבדיקה נעשתה על Claude Code אמיתי שערך ריפו open-source אמיתי (FastAPI + React), מה שנותן אמינות למספרים.

_The published benchmarks are striking: about 54% less code on average (up to 94% in some cases), roughly 20% cheaper and 27% faster, while keeping all safety guards intact. The tests ran on real Claude Code sessions editing a real open-source repo (FastAPI + React), lending credibility to the numbers._

**Example use case / דוגמת שימוש:** דוגמה מהמדדים: במשימת 'date picker' הסוכן נטה לבנות יותר מדי, ו-Ponytail קיצץ עד 94% מהקוד המיותר. בניגוד לפרומפט גנרי של 'כתוב שורה אחת', הסקיל שומר על כל המנגנונים הבטיחותיים לאורך הדרך.

_One benchmark example: on a date-picker task the agent tended to over-build, and Ponytail cut up to 94% of the unnecessary code. Unlike a bare one-liner prompt, the skill preserves every safety guard along the way._

**Why it matters for you / למה זה רלוונטי לך:** לאבי זה רלוונטי כי זה כלי קונקרטי לקונטקסט-אנג'ינירינג של סוכני קוד: הוא משנה את האופן שבו סוכן ניגש למשימת פיתוח, חוסך זמן ועלות, ועובד ישירות עם Claude Code וכלי סוכנים נוספים. זו דוגמה מדויקת לטכניקה שמוציאה יותר מהמודל בלי לשנות את המודל עצמו.

_This matters to Avi because it is a concrete context-engineering tool for coding agents: it changes how an agent approaches a dev task, saves time and cost, and works directly with Claude Code and other agent tools. It is a sharp example of squeezing more out of a model without touching the model itself._
