**What it does / מה זה עושה:** rea-video הוא כלי שרץ בתוך סוכני AI כמו Claude Code או Codex ומפרק כל סרטון לפי שוט: האם כל קטע צולם במצלמה, נוצר ב-AI או נבנה בקוד, ואיך אפשר לשחזר אותו. הפלט כולל דוח קריא (HTML או PDF) וקובץ VIDEO.md בפורמט פתוח שסוכנים יודעים לקרוא שכבה אחר שכבה.

_rea-video is a tool that runs inside agents like Claude Code or Codex and reverse-engineers any video shot by shot: whether each shot was filmed, AI-generated or coded, and how to remake it. It outputs a reader-friendly report (HTML or PDF) and a VIDEO.md file in an open format that agents can read layer by layer._

_The project has around 7,700 stars and is flagged as a Trendshift daily trend, tapping directly into the surge of AI-generated video that creators and marketers need to detect and understand.
