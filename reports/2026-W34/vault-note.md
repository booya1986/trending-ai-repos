## [deepseek-ai/deepseek-harness](https://github.com/deepseek-ai/deepseek-harness) — `TypeScript`
`ai-agents` `cordis` `dsh` `dsh-plugin`

**Stats:** ⭐ 183,048 · created 2026-08-13

**What it does / מה זה עושה:** DeepSeek Harness (dsh) הוא agent harness בקוד פתוח מבית DeepSeek AI, בנוי על ארכיטקטורה שבה הכל הוא פלאגין ומופעל על ידי Cordis. הכלי מריץ ממשק Web UI מקומי (localhost:3080) לניהול ואינטראקציה עם ה-agent.

_DeepSeek Harness (dsh) is an open-source agent harness from DeepSeek AI built on an everything-is-a-plugin architecture, powered by Cordis. It launches a local Web UI (port 3080) for running and interacting with the agent._

**Why it's trending / למה זה בטרנד:** מדובר בפרויקט חדש בתצוגה מקדימה למפתחים (developer preview) מבית DeepSeek, עם ארכיטקטורת פלאגינים גמישה שמעודדת קהילה להרחיב אותו (תגית dsh-plugin ייעודית). קרוב ל-183 אלף כוכבים משקף עניין עצום סביב agent harness חדש מחברת מודלים מובילה.

_This is a fresh developer-preview project from DeepSeek AI with a flexible plugin architecture designed for community extension (dedicated dsh-plugin topic). Nearly 183k stars reflects massive interest in a new agent harness from a leading model lab._

**Example use case / דוגמת שימוש:** מפתח יכול להריץ `npx @deepseek-ai/dsh web` ולפתוח מיד ממשק ווב מקומי לניהול agent, או לשכתב חלקים ב-harness על ידי כתיבת פלאגין משלו שמצטרף למערכת.

_A developer can run `npx @deepseek-ai/dsh web` to instantly get a local web UI for managing an agent, or extend the harness by writing a custom plugin that plugs into the system._

**Why it matters for you / למה זה רלוונטי לך:** לאבי זה רלוונטי כי מדובר בתשתית agent גמישה עם דגש על הרחבה מודולרית, בדיוק בתחום ה-agents וכלי productivity שהוא עוקב אחריהם. הארכיטקטורה מבוססת-פלאגינים יכולה להשפיע על איך בונים agentic tooling בעתיד.

_This matters to Avi because it is a flexible agent infrastructure emphasizing modular extension, right in the agents and productivity-tooling space he tracks. The plugin-based architecture could shape how agentic tooling is built going forward._

## [unslothai/unsloth](https://github.com/unslothai/unsloth) — `Python`
`agent` `ai` `chatgpt` `deepseek`

**Stats:** ⭐ 74,333 · created 2023-11-29

**What it does / מה זה עושה:** Unsloth היא אפליקציית דסקטופ להרצה ואימון של מודלי שפה ומודלי דיפוזיה מקומית, כולל תמיכה במודלים כמו Qwen3.8, Kimi K3, MiniMax-H3, Gemma 4, DeepSeek-V4 ו-FLUX. האפליקציה זמינה להורדה עבור Windows, macOS ולינוקס, ומאפשרת גם התקנה ידנית דרך סקריפט.

_Unsloth is a native desktop app for running and training LLMs and diffusion models locally, supporting models like Qwen3.8, Kimi K3, MiniMax-H3, Gemma 4, DeepSeek-V4 and FLUX. It ships as downloadable installers for Windows, macOS and Linux, or via a one-line install script._

**Why it's trending / למה זה בטרנד:** הפרויקט צובר תאוצה כי הוא מציג את עצמו כאפליקציית הדסקטופ הראשונה שמאפשרת גם הרצה וגם אימון (fine-tuning) של מודלים, כולל מודלים חדשים ובולטים כמו DeepSeek-V4 ו-Gemma 4. הנגישות (התקנה בקליק אחד, תמיכה בכל מערכות ההפעלה) מורידה את חסם הכניסה לאימון מודלים מקומי.

_It is gaining traction as the first desktop app to combine running and fine-tuning of LLMs and diffusion models in one native tool, including support for newly released models like DeepSeek-V4 and Gemma 4. One-click installers across Windows, macOS and Linux lower the barrier to local model training significantly._

**Example use case / דוגמת שימוש:** משתמש יכול להוריד את האפליקציה, ותוך כדי עבודה מקומית להריץ ולאמן מודל כמו Qwen3.8 או FLUX ליצירת תמונות, בלי להזדקק לענן.

_A user can download the app and locally run and fine-tune a model like Qwen3.8 or the FLUX image model, without relying on cloud infrastructure._

**Why it matters for you / למה זה רלוונטי לך:** עבור אבי, זו דוגמה ישירה לטכניקת fine-tuning שהופכת נגישה יותר, כלי שמאפשר לצוותים לבנות ולהתאים מודלים גנרטיביים (טקסט ותמונה) בלי תלות בענן, ורלוונטי גם לעבודה עם מודלים חדשים כמו DeepSeek-V4.

_For Avi, this is a direct example of fine-tuning becoming more accessible, a tool letting teams build and customize generative models (text and image) without cloud dependency, and relevant to working with new models like DeepSeek-V4._
