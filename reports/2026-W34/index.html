מה זה עושה

DeepSeek Harness (dsh) הוא הארנס agent קוד-פתוח מבית DeepSeek AI, בנוי על ארכיטקטורת 'הכל הוא פלאגין' ומופעל על ידי Cordis. הוא כולל ממשק Web UI שרץ מקומית ומאפשר להריץ אג'נטים בצורה מודולרית לחלוטין.

למה זה בטרנד

הפרויקט מגיע מ-DeepSeek AI, שם מוכר בעולם המודלים, וכבר צבר מעל 176 אלף כוכבים. הארכיטקטורה המבוססת פלאגינים לחלוטין והתמיכה בקהילת מפתחים דרך תג dsh-plugin הופכות אותו לפלטפורמת אג'נטים מעניינת לעקוב אחריה.

דוגמת שימוש

מריצים 'npx @deepseek-ai/dsh web' כדי לפתוח את ממשק ה-Web UI המקומי בכתובת 127.0.0.1:3080 ולהתחיל לעבוד עם אג'נטים ופלאגינים ישירות מהדפדפן.

למה זה רלוונטי לך

עבור אבי, זהו דוגמה נוספת לתשתית אג'נטים ניתנת להרחבה שממחישה איך ארכיטקטורת פלאגינים יכולה להפוך בניית agents לגמישה יותר. הפרויקט עדיין ב-developer preview עם שינויים תכופים, כך שכדאי לעקוב אחרי הבשלתו.
