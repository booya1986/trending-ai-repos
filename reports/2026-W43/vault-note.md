## [xerj-org/xerj](https://github.com/xerj-org/xerj) — `Rust`
`agent-memory` `ai-agents` `bm25` `claude-code`

**Stats:** ⭐ 13,239 · created 2026-06-30

**What it does / מה זה עושה:** XERJ הוא בינארי Rust יחיד שמשמש כמנוע חיפוש מקומי ושרת MCP עבור סוכני AI: הוא מאנדקס קוד, מסמכים, לוגים, קבצי JSONL/CSV ו-PDF ומאפשר חיפוש BM25, חיפוש וקטורי וחיפוש היברידי. הוא חושף API תואם Elasticsearch ותומך בזיכרון סוכנים (agent memory) ו-RAG, כולל חיפוש קוד בלי grep.

_XERJ is a single Rust binary that acts as a local-first search engine and MCP server for AI agents: it indexes code, docs, logs, JSONL/CSV and PDFs, enabling BM25 full-text, vector and hybrid search. It exposes an Elasticsearch-compatible API and supports agent memory and RAG, including code search without grep._

**Why it's trending / למה זה בטרנד:** הפרויקט צבר יותר מ-13,000 כוכבים ומסומן כ-Trendshift, עם תמיכה נייטיבית ב-MCP ועבודה ישירה עם Claude Code ו-Cursor. הוא מציע בינארי יחיד ללא JVM, תאימות ES-YAML גבוהה (1366/1369) ו-Corpus Hub עם מאות קורפוסי זיכרון מוכנים.

_The project has over 13,000 stars and a Trendshift badge, with native MCP support and direct integration with Claude Code and Cursor. It ships as a single binary with no JVM, high ES-YAML conformance (1366/1369), and a Corpus Hub offering hundreds of ready reference memory corpora._

**Example use case / דוגמת שימוש:** מפתח יכול להריץ את XERJ מול מאגר קוד גדול ולבצע חיפוש קוד היברידי (BM25 ווקטורי) במקום להשתמש ב-grep, ולקבל תשובות מדויקות יותר תוך פחות טוקנים לפי case study של reference coding. סוכן עם חיבור MCP יכול גם לשמור ולשלוף זיכרון (/memory) ישירות דרך השרת.

_A developer can run XERJ against a large codebase and perform hybrid (BM25 plus vector) code search instead of grep, getting more precise answers with fewer tokens per the reference-coding case study. An MCP-connected agent can also store and retrieve memory (/memory) directly through the server._

**Why it matters for you / למה זה רלוונטי לך:** לאבי זה רלוונטי כי זה כלי תשתית ממשי לסוכנים ולכלי Claude: הוא נותן לסוכנים זיכרון, RAG וחיפוש קוד איכותי בלי תלות בשירות ענן, ומתחבר ישירות ל-MCP, Claude Code ו-Cursor.

_This matters to Avi because it is real infrastructure for agents and Claude tooling: it gives agents memory, RAG and quality code search without depending on a cloud service, and plugs directly into MCP, Claude Code and Cursor._

_ComfyUI is a node graph based AI creation engine for generating images, video, 3D models, and audio using diffusion models. Its modular interface gives full control over every model and parameter, and it natively supports the latest open-source state of the art models._

**Why it's trending / למה זה בטרנד:** הפרויקט צבר מעל 142 אלף כוכבים ונחשב למנוע ההסקה המקומי המהיר ביותר בעולם, עם יכולת להריץ מודלים גדולים אפילו על 4GB VRAM בזכות טכנולוגיית סטרימינג משקלים אסינכרונית. הוא גם מציע nodes שותפים לגישה למודלים סגורים כמו Nano Banana ו-Seedance.

_The project has over 142k stars and is positioned as the fastest local inference engine for diffusion models, able to run even huge open-source models on as little as 4GB VRAM via asynchronous weight streaming. It also offers partner nodes giving access to closed-source models like Nano Banana and Seedance._

**Example use case / דוגמת שימוש:** משתמש יכול לבנות גרף node-based שמשלב מודל open-source מקומי עם node שותף למודל סגור, ולהפיק סרטון או תמונה באיכות גבוהה תוך שליטה מדויקת בכל שלב בתהליך. הכל רץ מקומית על Windows, Linux או macOS דרך אפליקציית desktop.

_A user can build a node-based graph combining a local open-source model with a partner node for a closed-source model, producing high quality images or video with precise control over every step. Everything runs locally on Windows, Linux, or macOS via the desktop application._
