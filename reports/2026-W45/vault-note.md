## [thedotmack/claude-mem](https://github.com/thedotmack/claude-mem) — `TypeScript`
`ai` `ai-agents` `ai-memory` `anthropic`

**Stats:** ⭐ 113,770 · created 2025-08-31

**What it does / מה זה עושה:** claude-mem היא מערכת זיכרון מתמיד לסוכני קוד: היא לוכדת כל מה שהסוכן עושה במהלך סשן, דוחסת את זה בעזרת AI, ומזריקה את ההקשר הרלוונטי חזרה לסשנים עתידיים. המערכת עובדת עם Claude Code, OpenClaw, Codex, Gemini, Hermes, Copilot, OpenCode ועוד.

_claude-mem is a persistent memory compression system for coding agents: it captures everything an agent does during a session, compresses it with AI, and injects the relevant context back into future sessions. It works across Claude Code, OpenClaw, Codex, Gemini, Hermes, Copilot, OpenCode and more._

**Why it's trending / למה זה בטרנד:** המאגר צבר מעל 113 אלף כוכבים, מספר שמצביע על אימוץ רחב מאוד בקהילת מפתחי ה-AI. התמיכה במספר ענק של שפות (כולל עברית) ובמגוון סוכנים מראה על קהילה גלובלית פעילה ושימוש יומיומי אמיתי.

_The repo has amassed over 113,000 stars, signaling very broad adoption in the AI developer community. Support for dozens of languages (including Hebrew) and compatibility with many different agents points to an active global community and real daily usage._

**Example use case / דוגמת שימוש:** מפתח עובד על פרויקט קוד גדול לאורך ימים עם Claude Code: claude-mem דוחס את ההיסטוריה של כל סשן עבודה כך שבפעם הבאה שהוא פותח את הסוכן, הוא לא צריך להסביר הכל מחדש, ההקשר הרלוונטי כבר שם.

_A developer working on a large codebase across multiple days with Claude Code: claude-mem compresses the history of each work session so the next time the agent is opened, the relevant context is already there without re-explaining everything._

**Why it matters for you / למה זה רלוונטי לך:** לאבי זה רלוונטי כי זה בדיוק סוג הכלי שהופך סוכני קוד לעוזרי עבודה אמיתיים: זיכרון מתמיד הוא אבן יסוד בהנדסת הקשר (context engineering) ובבניית סוכנים שעובדים לאורך זמן, לא רק בשיחה בודדת.

_This is directly relevant to Avi because persistent memory is a cornerstone of context engineering, turning coding agents into real long-term work assistants rather than tools limited to a single conversation._

## [KKKKhazix/agent-autoloop](https://github.com/KKKKhazix/agent-autoloop) — `TypeScript`
`ai-agents` `automation` `claude-code` `cli`

**Stats:** ⭐ 3,474 · created 2026-11-03

**What it does / מה זה עושה:** Agent Autoloop הוא ליבת אוטומציה קלה משקל שמריצה סוכני שורת פקודה כמו Claude Code ו-Codex ברקע: הם מקבלים משימות, ממשיכים לבד, ומסיימים סיבוב ויוצאים מהתהליך. רק כשצריך החלטה (מחיקת נתונים, הוצאת כסף, שליחת הודעה החוצה) נשלחת כרטיסייה להחלטה דרך Feishu, Slack, Discord או התראת דסקטופ. הכל רץ מקומית על Mac או Linux ללא שרת ענן, עם חוקים שמוגדרים בקובץ rules.json.

_Agent Autoloop is a lightweight, zero-dependency automation kernel that runs CLI agents like Claude Code and Codex in the background: they pick up tasks, keep working autonomously, and exit the process after each round. It only pings the user with a decision card (via Feishu, Slack, Discord or desktop notification) when something risky needs sign-off, like deleting data or spending money. Everything runs locally on Mac or Linux with no cloud server, configured through a simple rules.json file._

**Why it's trending / למה זה בטרנד:** הפרויקט פותר בעיה אמיתית: סוכני שורת פקודה שדורשים שמישהו ישב מול הטרמינל. הארכיטקטורה הניתנת להרחבה (מקורות אירועים, סוכנים, ערוצי התראה, כל אחד כפלאגין נפרד) ותמיכה מובנית ב-Claude Code ו-Codex הופכים אותו לרלוונטי מאוד לזרימות עבודה אוטונומיות עם סוכנים.

_It solves a real pain point: CLI agents that normally require someone glued to the terminal. The pluggable architecture (event sources, agents, notification channels, deploy pipelines all swappable) plus native support for Claude Code and Codex make it very relevant to the current wave of autonomous agent workflows._

**Example use case / דוגמת שימוש:** דוגמה מהREADME: חוק שרץ כל בוקר ב-9:00, מעביר ל-Codex את המשימה לסכם הערות מהיום הקודם ולכתוב דוח בוקר, הכל בתיקייה מוגדרת. דוגמה נוספת: כשנפתח Issue חדש בגיטהאב, הכלל מעביר אותו אוטומטית ל-Codex לטיפול, עד שלוש משימות במקביל.

_From the README: a rule that fires every morning at 9am hands Codex the task of summarizing yesterday's notes and writing a morning report in a specified directory. Another rule automatically routes newly opened GitHub issues to Codex for handling, running up to three in parallel._

**Why it matters for you / למה זה רלוונטי לך:** לאבי זה מעניין כי זה בדיוק סוג הכלי שהופך סוכן מצ'אטבוט תגובתי לעובד שממשיך לבד ועוצר רק לקבלת החלטות אמיתיות, רעיון מרכזי בכל שיחה על אגנטים שעושים עבודה אמיתית. זה גם מדגים שימוש מעשי ב-MCP, Claude Code ו-Codex יחד.

_This matters to Avi because it embodies the shift from reactive chatbot agents to workers that act autonomously and only stop for genuine decisions, a core theme in agent tooling right now. It is also a concrete example of integrating Claude Code, Codex and MCP-style event-driven automation together._
