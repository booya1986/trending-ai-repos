מה זה עושה

DeepSeek Harness (dsh) הוא מסגרת (harness) קוד פתוח להרצת סוכני AI, שפותחה בידי DeepSeek AI. הארכיטקטורה שלה מבוססת על עיקרון של 'הכל הוא פלאגין' ובנויה על גבי הספרייה Cordis. אפשר להריץ אותה מהר דרך npx עם ממשק Web UI מקומי, או לבנות אותה מהמקור.

למה זה בטרנד

הפרויקט מגיע מ-DeepSeek AI, שם מוכר וחזק בתחום ה-AI, מה שמסביר חלק מההתעניינות המיידית. הארכיטקטורה המודולרית שמבוססת כולה על פלאגינים, יחד עם תיעוד, Discord קהילתי ואפשרות הרצה מיידית עם npx, הופכים אותו לנגיש לקהילת מפתחי סוכנים.

דוגמת שימוש

מפתח יכול להריץ `npx @deepseek-ai/dsh web` כדי לפתוח מיידית ממשק web מקומי לניהול סוכן AI, בלי להתקין תלויות מורכבות. מי שרוצה להרחיב את היכולות יכול לכתוב פלאגין משלו ולסמן אותו בתגית dsh-plugin כדי שאחרים ימצאו אותו.

למה זה רלוונטי לך

עבור אבי, זהו דוגמה ישירה לתשתית agent harness מודולרית מחברה מובילה, רלוונטית לעבודה עם סוכנים ו-tooling. הגישה של 'הכל פלאגין' יכולה להשפיע על איך בונים כלי agent עתידיים, אבל חשוב לציין שזו גרסת developer preview עם שינויים צפויים שישברו תאימות.

מה זה עושה

ffmpeg-skill הוא כלי עריכת וידאו מקומי לסוכני קידוד כמו Claude Code, Cursor ו-Codex, הכולל 42 כלי FFmpeg עם חוזה קריא למכונה ושרת MCP. הסוכן יכול לחתוך, להוסיף כתוביות, לשנות יחס תמונה, לנרמל עוצמת קול ולייצא לפלטפורמות שונות, הכל מקומית ללא ענן או מפתחות API.

למה זה בטרנד

הפרויקט צובר תאוצה כי הוא מרחיב את היכולות של סוכני קוד מעבר לכתיבת קוד אל תחום עריכת הווידאו בפועל, תוך שימוש בפייתון סטנדרטי בלבד וללא תלות בענן. התמיכה ב-MCP והתאימות למספר סביבות סוכנים (Claude Code, Cursor, Codex) הופכת אותו לרלוונטי לגל הנוכחי של כלי אוטומציה מבוססי סוכנים.

דוגמת שימוש

דוגמה מה-README: caption.py עם --animate pop --karaoke יוצר כתוביות מונפשות עם הדגשת קריוקי, ו-fit.py עם --aspect 9:16 --fit crop ממיר סרטון מ-16:9 ל-9:16. כלים נוספים כוללים silence.py להסרת שתיקות ו-loudness.py לנרמול עוצמת קול ל-14 LUFS.

למה זה רלוונטי לך

עבור אבי, זה דוגמה מוחשית לסוכן AI שעושה עבודה אמיתית ולא רק מייצר טקסט, עם בדיקה עצמית של הפלט (measured output) שמתחבר ישירות לנושאי עריכת וידאו ויצירת תוכן. השילוב עם MCP ו-Claude Code הופך אותו לרלוונטי במיוחד לסדר העדיפויות שלו סביב סוכנים וכלי Claude.
