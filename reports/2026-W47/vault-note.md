_ffmpeg-skill is a local video editor for coding agents like Claude Code, Cursor and Codex, providing 42 FFmpeg tools with a machine-readable contract and an MCP server. The agent can cut footage, add captions, reframe aspect ratio, normalize loudness and export for platforms, all locally with no cloud or API keys._

**Why it's trending / למה זה בטרנד:** הפרויקט צובר תאוצה כי הוא מרחיב את היכולות של סוכני קוד מעבר לכתיבת קוד אל תחום עריכת הווידאו בפועל, תוך שימוש בפייתון סטנדרטי בלבד וללא תלות בענן. התמיכה ב-MCP והתאימות למספר סביבות סוכנים (Claude Code, Cursor, Codex) הופכת אותו לרלוונטי לגל הנוכחי של כלי אוטומציה מבוססי סוכנים.

_The project is gaining traction because it extends coding agents beyond writing code into actual video editing work, using only the Python standard library with no cloud dependency. Its MCP support and compatibility across multiple agent environments (Claude Code, Cursor, Codex) make it relevant to the current wave of agentic automation tools._

**Example use case / דוגמת שימוש:** דוגמה מה-README: caption.py עם --animate pop --karaoke יוצר כתוביות מונפשות עם הדגשת קריוקי, ו-fit.py עם --aspect 9:16 --fit crop ממיר סרטון מ-16:9 ל-9:16. כלים נוספים כוללים silence.py להסרת שתיקות ו-loudness.py לנרמול עוצמת קול ל-14 LUFS.

_From the README: caption.py with --animate pop --karaoke generates animated captions with karaoke highlighting, and fit.py with --aspect 9:16 --fit crop reframes a 16:9 video to 9:16. Other tools include silence.py for removing silence and loudness.py for normalizing audio to -14 LUFS._

**Why it matters for you / למה זה רלוונטי לך:** עבור אבי, זה דוגמה מוחשית לסוכן AI שעושה עבודה אמיתית ולא רק מייצר טקסט, עם בדיקה עצמית של הפלט (measured output) שמתחבר ישירות לנושאי עריכת וידאו ויצירת תוכן. השילוב עם MCP ו-Claude Code הופך אותו לרלוונטי במיוחד לסדר העדיפויות שלו סביב סוכנים וכלי Claude.

_For Avi, this is a concrete example of an AI agent doing real production work rather than just generating text, with self-verification of output that ties directly into video editing and content creation workflows. Its integration with MCP and Claude Code makes it especially relevant to his focus on agents and Claude tooling._
