## [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd) — `Python`
`adhd` `claude-` `claude-code-plugin` `claude-skills`

**Stats:** ⭐ 39,460 · created 2026-05-13

**What it does / מה זה עושה:** סקיל (Skill) ל-Claude Code ולסוכני קידוד אחרים שגורם להם להוציא תשובות בפורמט ADHD-friendly: פעולה ראשונה, שלבים ממוספרים, בלי הקדמות ובלי סיכומים מיותרים. מבוסס על 10 חוקים שמוגדרים בקובץ SKILL.md ואפשר לערוך אותם.

_A skill for Claude Code and other coding agents that forces ADHD-friendly output: action first, numbered steps, no preamble and no closing fluff. It runs on 10 defined rules in SKILL.md that can be forked and customized._

**Why it's trending / למה זה בטרנד:** הרעיון פשוט ומדבר לכולם: כל מי שמשתמש בסוכני קידוד סובל מתשובות מבולבלות ומלאות בקדימות. הרפו קיבל 39K כוכבים כי הוא פותר כאב יומיומי אמיתי בממשק שימוש בכלים כמו Claude Code, בלי צורך באבחון ADHD.

_The idea is simple and universally relatable: anyone using coding agents suffers from buried answers and rambling preambles. With 39K stars, it clearly hit a nerve by fixing a daily UX pain point in tools like Claude Code, no ADHD diagnosis required._

**Example use case / דוגמת שימוש:** הדוגמה בריפו מראה איך תשובה כמו 'שאלה נהדרת! תן לי לחשוב על זה...' עם הסברים מפוזרים על middleware ו-token verification, הופכת ל: 'הרץ npm install jsonwebtoken@latest, ואז ערוך src/auth.ts:42' עם שלבים ממוספרים וצעד הבא קונקרטי.

_The README example shows a rambling answer like 'Great question! Let me think about this...' about middleware and token verification transformed into: 'Run npm install jsonwebtoken@latest, then edit src/auth.ts:42' with numbered steps and one concrete next action._

**Why it matters for you / למה זה רלוונטי לך:** לאבי זה מייצג טכניקת prompt/context engineering זעירה אבל מדויקת: בלי לשנות מודל או להוסיף כלים, רק בעיצוב פלט, אפשר להפוך סוכן קידוד לעוזר יעיל בהרבה בעבודה יומיומית. זה מתחבר ישירות לתחום ה-Claude tooling וה-skills שהוא עוקב אחריו.

_For Avi this is a tiny but precise context-engineering technique: without changing the model or adding tools, just by shaping output format, a coding agent becomes far more useful for real daily work. It ties directly into the Claude tooling and skills ecosystem he tracks closely._

## [Graphify-Labs/graphify](https://github.com/Graphify-Labs/graphify) — `Python`
`ai-agents` `antigravity` `ast` `claude-code`

**Stats:** ⭐ 116,840 · created 2026-04-03

**What it does / מה זה עושה:** Graphify הופך כל קודבייס, כולל תיעוד, סכמות SQL, קבצי קונפיגורציה וקבצי PDF, לגרף ידע שניתן לשאול אותו שאלות. זהו skill בשם /graphify עבור Claude Code, Cursor, Codex ו-Gemini CLI, שמבצע פענוח AST דטרמיניסטי מקומי ומסביר כל קשר בגרף בלי להשתמש ב-vector store.

_Graphify turns any codebase, along with its docs, SQL schemas, configs, and PDFs, into a queryable knowledge graph. It ships as a /graphify skill for Claude Code, Cursor, Codex, and Gemini CLI, using local deterministic AST parsing where every edge in the graph is explained, with no vector store involved._

**Why it's trending / למה זה בטרנד:** הכלי נמצא בממשק ישיר עם כלי הפיתוח החמים ביותר של הרגע: Claude Code, Cursor, Codex ו-Gemini CLI, ומציע חלופה דטרמיניסטית ושקופה ל-RAG מבוסס וקטורים בהבנת קוד. הגישה של 'כל קשר מוסבר' פונה לצורך גובר בשקיפות ואמינות בכלי סוכנים לקוד.

_It plugs directly into the hottest coding agent tools right now: Claude Code, Cursor, Codex, and Gemini CLI, offering a deterministic, transparent alternative to vector-store-based RAG for code understanding. The 'every edge explained' approach speaks to a growing demand for transparency and reliability in agentic coding tools._

**Example use case / דוגמת שימוש:** מפתח שעובד עם Claude Code יכול להריץ את /graphify על repo גדול הכולל קוד, סכמות DB וקבצי תיעוד, ולקבל גרף ידע שניתן לשאול אותו על תלויות בין קבצים או קשרים בין טבלאות, בלי צורך בהטמעות וקטוריות.

_A developer working in Claude Code can run /graphify on a large repo containing code, DB schemas, and docs, and get back a knowledge graph they can query for file dependencies or table relationships, without needing vector embeddings._

**Why it matters for you / למה זה רלוונטי לך:** לאבי זה רלוונטי כי מדובר בכלי agentic שמרחיב את היכולות של Claude Code וכלים דומים, ומטפל בבעיה מרכזית בהבנת קוד גדול על ידי מודלים: הקשר מדויק ומוסבר במקום חיפוש וקטורי מטושטש. זה מתחבר ישירות לתחום ה-context engineering שמעניין אותו.

_This matters to Avi because it is an agentic tool that extends Claude Code and similar tools, tackling a core problem in large-codebase understanding by giving precise, explainable context instead of fuzzy vector search. It ties directly into the context engineering space he tracks._

_The repo is explicitly built for agents, shipping a skills system (npx skills add) that teaches any AI coding agent to produce video from a single prompt. With nearly 49k stars and a stack combining FFmpeg, GSAP and Puppeteer, it stands out as a creative-production tool designed to run inside automated agent workflows rather than a manual editor._

**Example use case / דוגמת שימוש:** אפשר לבקש מסוכן AI, לאחר התקנת הסקילים, ליצור סרטון פרסומת של מוצר באורך 10 שניות עם כותרת שדוהה פנימה, וידאו רקע ומוזיקת רקע עדינה, והכלי מרנדר את זה כקובץ MP4.

_After installing the skills, you can ask an AI agent to build a 10-second product intro with a fade-in title, a background video, and subtle background music, and the tool renders it as an MP4._

**Why it matters for you / למה זה רלוונטי לך:** לאבי זה רלוונטי כי זה בדיוק המפגש בין ייצור קריאייטיב (וידאו) לבין סוכנים שעושים עבודה אמיתית: כלי שמאפשר לסוכן קידוד לכתוב HTML ולקבל וידאו מוגמר בלי מעורבות אנושית ידנית באדיטור.

_This matters to Avi because it sits exactly at the intersection of creative production (video) and agents that do real work: a tool letting a coding agent write HTML and get a finished video back, with no manual editor involved._
